# Baseline Comparison Eval

- Cases run: 10
- Evaluation method: DeepSeek semantic judge as primary score; keyword matching retained as diagnostics; forbidden claims retained as safety penalty.
- Judge model: deepseek-chat
- Baseline model fixture: ChatGPT GPT-5.5 Thinking same-input baseline run
- Kiwi Agent average score: 0.97
- Generic ChatGPT-style baseline average score: 0.86
- Average gain: 0.11
- Win rate: 1
- Min average gate: 0.78
- Per-case fail gate: 0.6

## Interpretation
Kiwi Agent outperformed the generic ChatGPT-style baseline by 0.11 average score points under the semantic judge method.
This is a feedback-level benchmark only: it compares same-input baseline feedback against Kiwi Agent feedback. It does not exercise CV upload, JD parsing, interview runtime, voice, storage, auth, UI, or report download flows.
